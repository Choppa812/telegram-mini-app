# GiftAutoBuyer — личный Telegram Mini App

Исходная база: https://github.com/Choppa812/telegram-mini-app, production-проект пользователя на Vercel. Эта доработка сохранена локально, в GitHub и Vercel не опубликована.

## Текущий статус

Это рабочая основа приложения, **не полная функциональная копия Gift Satellite**. Разделов «Задания» и «Лидеры» нет. Поиск, подписки и профиль оформлены по наблюдаемой структуре оригинала. Доступны серверное создание, изменение, включение/пауза и удаление подписок; паттерны номера, выбор атрибутов, площадок, настройка уведомлений, исключения и пресеты. Данные сохраняются в SQLite.

Баланс пока отображается «—». Добавлены страницы кошелька, пополнения, вывода, Stars, стейкинга, рефералов и уровней. Реальные финансовые операции и начисления не подключены; соответствующие кнопки заблокированы. Уровни рассчитываются по подтверждённым покупкам, аналитика прибыли — только по подтверждённым продажам. Внешний API поддерживает ключи только для чтения подписок, с ротацией и отзывом. Подключения к API площадок отсутствуют. Автопокупка заблокирована на клиенте и сервере.

Иллюстрации коллекций и моделей, изображения узоров и точные градиенты фонов прочитаны из отображаемого интерфейса оригинала 5 октября 2026 года. Изображения сохраняются в `public/gift-assets` и включаются в сборку: загрузка картинок не зависит от авторизации в оригинальном боте. Смайлики вместо подарков удалены. При отсутствии изображения показывается явная подпись, а не другой подарок. Это снимок каталога на дату просмотра; новые коллекции потребуют обновления.

## Запуск

Нужен Node.js 24. Установите зависимости командой `pnpm install`, затем `pnpm build`. Скопируйте `.env.example` в `.env` и заполните только на сервере. Запуск: `pnpm start`.

Для локального просмотра установите `LOCAL_PREVIEW=1`, после запуска откройте http://127.0.0.1:4173/. В этом режиме сервер привязан к loopback, проверяет Host и Origin, выдаёт локальный токен сессии. Никогда не используйте этот режим при публикации и не проксируйте его наружу.

Для рабочего запуска: `LOCAL_PREVIEW=0`, `BOT_TOKEN`, `OWNER_ID` и `APP_ORIGIN` должны быть заданы. Telegram initData проверяется HMAC, возрастом и ID владельца. Сервер по умолчанию слушает loopback; для внешнего доступа нужен HTTPS reverse proxy. `.env`, база и токены исключены из Git. Telegram initData не выводится в логи.

## Источник предложений

Добавлена ежедневная оценка минимальных цен и порогов по всем коллекциям и отдельно по Black: минимум минус не менее 5 GRAM, больший запас при слабом спросе, блокировка при нехватке продаж, неизвестных расходах и устаревших данных. Результат сохраняется в SQLite. Источник `MARKET_ANALYSIS_FILE` ещё не подключён, поэтому живое ежедневное обновление не запущено. Полная схема и ограничения: [deploy/PRICING.md](deploy/PRICING.md).

Монитор читает нормализованный JSON по `MARKET_DATA_FILE`. Это интерфейс для будущих адаптеров, а не уже готовое подключение к торговым площадкам. Файл должен обновляться собственным источником данных; по умолчанию данные старше десяти секунд отклоняются (`MAX_FEED_AGE_MS=10000`). Записывайте новый файл атомарно.

Формат:

```json
{
  "generatedAt": "актуальная дата ISO 8601",
  "catalog": [
    {"name":"Lol Pop", "models":["Satellite"], "backdrops":["Black"], "symbols":[]}
  ],
  "offers": [
    {"id":"уникальный id площадки", "market":"MRKT", "collection":"Lol Pop", "number":"123456", "model":"Satellite", "backdrop":"Black", "symbol":"", "priceTon":20}
  ],
  "sales": []
}
```

Это описание схемы, не реальный рыночный снимок. Продажи имеют те же поля плюс `date` в ISO 8601. `catalog` необязателен; встроенные названия коллекций, моделей, фонов и узоров собраны при просмотре оригинала. Живые цены и сведения о редкости для большинства коллекций требуют источника данных.

Монитор по умолчанию раз в две секунды сопоставляет предложения с включёнными подписками (`MONITOR_INTERVAL_MS=2000`, допустимо 1000–60000). При настроенных `BOT_TOKEN` и `OWNER_ID` он отправляет Telegram-уведомления о новых предложениях и изменении цен в пределах лимита. Без токена уведомления не отправляются. Повторы подавляются сохранением состояния; при сетевой неопределённости после отправки возможен повтор, поскольку Bot API не обеспечивает exactly-once. Записи событий пока не очищаются автоматически. Реальная доставка в Telegram ещё не проверена. Цикл мониторинга не означает гарантированную скорость покупки; торговля пока отсутствует.

## Размещение

Текущий сервер использует локальный SQLite и постоянный таймер. **Он не может работать как обычная бессостоя́тельная функция Vercel с временной файловой системой.** Vercel можно оставить для клиента, но для этого потребуется настроить API-прокси к серверу. Альтернатива — разместить клиент и сервер вместе на VPS или другом хостинге с постоянным процессом и диском.

Проект Vercel: `telegram-mini-app`, репозиторий `Choppa812/telegram-mini-app`, бот `@GiftAutoBuyer812_bot`. Оплата или создание нового хостинга не выполнялись. Текущий production-сайт сохранён.

Для согласованной реакции за несколько секунд подготовлены `Dockerfile`, `compose.yaml`, HTTPS-прокси и пример API-rewrites для Vercel. Инструкция: [deploy/README.md](deploy/README.md). Бюджет VPS — до 1 000 ₽/месяц. Конфигурация Compose проверена; образ не собран, сервер не развёрнут, TLS не проверен.

## Проверки

`pnpm test`

Тестируются проверка Telegram-подписи и владельца, срок авторизации, паттерны номера, атрибуты, некорректные цены и количества, отказ автопокупки, срок годности источника, API CRUD и сохранение после перезапуска. Сборка Vite и создание подписки через браузер также проверены. Реальные рыночные интеграции и финансовые операции не тестировались.
