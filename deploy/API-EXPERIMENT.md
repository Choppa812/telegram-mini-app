# Эксперимент с API Gift Satellite

Ветка experiment/gift-satellite-api отделена от основной версии личного Mini App. Здесь сохранён эксперимент ежедневных порогов; он не подключён к оригинальному API и не выполняет финансовых операций.

Предпочтительное исследование: управление уже существующим Gift Satellite вместо разработки второго торгового интерфейса, если провайдер действительно предоставляет нужные методы. Проверить чтение каталога, минимумов, завершённых продаж; чтение и изменение своих подписок/слотов; инвентарь и подтверждённые покупки; выставление на продажу, изменение цены, снятие с продажи; права ключа, тарифы, лимиты, идентификаторы операций и защиту от дублей. Наличие ключа само по себе не подтверждает эти возможности.

Если API умеет менять слоты, фоновая программа может периодически пересчитывать цены, а оригинальный бот — выполнять существующую автопокупку. Для самостоятельной продажи требуется отдельный метод оригинала или API площадки. Ключ не сохранялся и не включён в Git.

Vercel Cron подходит для периодического анализа: Hobby — минимум раз в день, Pro — раз в минуту. Реакция за секунды требует событий/webhook от провайдера либо постоянного рабочего процесса. Не гарантировать прибыль; учитывать комиссии, исполнимые цены, капитал, ликвидность, риск и лимиты расходов.

Источник ограничений Vercel: https://vercel.com/docs/cron-jobs/usage-and-pricing
