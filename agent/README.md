# Gift Satellite Black controller

Проект Vercel `gift-price-controller` использует производственную ветку `gift-price-controller`, корень `agent`, адрес https://gift-price-controller.vercel.app. VPS не используется. Отдельный Telegram-бот владельца — `@GiftPriceControl812_bot`. Секреты API Gift Satellite, Telegram и Redis хранятся только в переменных Vercel. Upstash Redis хранит паузу, последний отчёт и защиту от повторного ежедневного запуска.

Vercel Cron вызывает `/api/daily` по расписанию `0 6 * * *` UTC. Для Hobby точная минута не гарантируется. При активной `/pause` задача ничего не меняет и не присылает утренних сообщений. `/resume` разрешает следующую ежедневную проверку. Codex heartbeat в текущем чате запланирован на 10:15 по Москве для дополнительного анализа свежих данных; он не должен дублировать штатный отчёт Vercel.

11 октября 2026 через документированный Gift Satellite API (`Authorization: Token …`) подтверждены чтение и запись `/user/update-subscription/:id`. План обновлён 14 октября после проверки баланса 87,23 TON и 76 коллекций Black. Целевые пять слотов:

Пять потолков суммарно составляют 80,68 TON, с расчётным резервом 3% на комиссию покупки — 83,10 TON. Дневная задача проверяет текущий баланс, Black-листинги Portals/MRKT и завершённые продажи выбранных моделей за 24 часа. Она может снизить потолок по нижнему квартилю цены продаж: `(Q1 × 0,95 − 3 TON) / 1,03`. Отступ от текущего листинга не фиксирован в 5 TON. Модель без двух продаж за сутки не включается при очередном обновлении. Если данных недостаточно, слот пропускается. Каждая запись проходит проверку паузы непосредственно перед PUT и подтверждается повторным GET. Отчёт с фактическими изменениями приходит в бот и доступен через `/report`. Ручная `/applyblack` запускает тот же план сейчас. `/positions`, `/models`, `/cross`, `/fees` и другие команды дают данные для анализа.

Отключение старых слотов через API провайдера сбросило их цену автопокупки и количество до пустого значения и нуля. Чтобы вернуть прежнюю стратегию, эти настройки нужно задать заново. Для B-Day Candle и Whip Cupcake используются существующие выключенные слоты Record Player и Jelly Bunny; новые слоты не покупаются. API покупки/продажи подарков этим проектом не вызывается. Автопокупку по активным слотам осуществляет сам Gift Satellite. `/pause` останавливает только этот контроллер и его сообщения, но **не** выключает автопокупку Gift Satellite по уже установленным лимитам.

Функция `/api/telegram` принимает только подписанный webhook и команды владельца в личном чате. `/api/daily` принимает только секрет Vercel Cron. Падение Redis запрещает записи. Перед каждым изменением контроллер проверяет актуальную цену рынка; наблюдаемые цены и частота сделок не гарантируют прибыльной перепродажи. Автоматическая продажа подарков и полная копия Mini App не реализованы.

Тесты: из каталога `agent` выполнить `node --test *.test.js`. Они используют поддельный API и не проводят платежей.
