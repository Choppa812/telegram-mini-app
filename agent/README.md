# Gift Satellite Black controller

Проект Vercel `gift-price-controller` использует производственную ветку `gift-price-controller`, корень `agent`, адрес https://gift-price-controller.vercel.app. VPS не используется. Отдельный Telegram-бот владельца — `@GiftPriceControl812_bot`. Секреты API Gift Satellite, Telegram и Redis хранятся только в переменных Vercel. Upstash Redis хранит паузу, последний отчёт и защиту от повторного ежедневного запуска.

Vercel Cron вызывает `/api/daily` по расписанию `0 6 * * *` UTC. Для Hobby точная минута не гарантируется. При активной `/pause` задача ничего не меняет и не присылает утренних сообщений. `/resume` разрешает следующую ежедневную проверку. Codex heartbeat в текущем чате запланирован на 10:15 по Москве для дополнительного анализа свежих данных; он не должен дублировать штатный отчёт Vercel.

11 октября 2026 через документированный Gift Satellite API (`Authorization: Token …`) подтверждены чтение и запись `/user/update-subscription/:id`. Из 28 имеющихся слотов 25 отключены от автопокупки. Активны только:

| Коллекция | Фон | Модели | Лимит, TON | Количество |
| --- | --- | --- | ---: | ---: |
| Vice Cream | Black | Birthday, Sushi, Bamboo Ice, Pine Cone, Cavendish, Vanilla | 15.79 | 1 |
| Chill Flame | Black | Signal Flare, Olympia, Ionic Column, Eternal Flame, Oil Lamp | 17.44 | 1 |
| Xmas Stocking | Black | Vintage, Fairy Tale, Caramel Fest, Lime Treats | 15.27 | 1 |

Это начальный выбор по продажам Black за предшествующие 24 часа. Три предельные цены вместе с резервом 3% на комиссию покупки составляют 49.955 TON. Ежедневная задача читает свежий минимальный листинг Black на Portals и Mrkt и ставит лимит не выше `min(начальный потолок, минимальная цена − 5 TON)`. По полной истории продаж Black за 24 часа она также пересматривает модели, оставляя достаточно часто продававшиеся и подходящие по цене; при неполной истории сохраняет предыдущий выбор. Если слот выключен, покупка уже исчерпала его лимит или доступного баланса мало, задача его пропускает. Каждая запись проходит проверку паузы непосредственно перед PUT и подтверждается повторным GET. Отчёт с фактическими изменениями приходит в бот и доступен через `/report`. Ручная `/applyblack` запускает тот же план сейчас. `/positions`, `/positions Vice Cream`, `/models Vice Cream`, `/blackscan`, `/inspect`, `/fees` и другие команды дают данные для анализа.

Отключение старых слотов через API провайдера сбросило их цену автопокупки и количество до пустого значения и нуля. Чтобы вернуть прежнюю стратегию, эти настройки нужно задать заново. Слот Xmas Stocking получен перенастройкой ранее выключенного Lol Pop; новые слоты не покупались. API покупки/продажи подарков этим проектом не вызывается. Автопокупку по трём активным слотам осуществляет сам Gift Satellite. `/pause` останавливает только этот контроллер и его сообщения, но **не** выключает автопокупку Gift Satellite по уже установленным лимитам.

Функция `/api/telegram` принимает только подписанный webhook и команды владельца в личном чате. `/api/daily` принимает только секрет Vercel Cron. Падение Redis запрещает записи. Перед каждым изменением контроллер проверяет актуальную цену рынка; наблюдаемые цены и частота сделок не гарантируют прибыльной перепродажи. Автоматическая продажа подарков и полная копия Mini App не реализованы.

Тесты: из каталога `agent` выполнить `node --test *.test.js`. Они используют поддельный API и не проводят платежей.
