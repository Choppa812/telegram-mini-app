# Gift Satellite Black controller

Проект Vercel `gift-price-controller` использует производственную ветку `gift-price-controller`, корень `agent`, адрес https://gift-price-controller.vercel.app. VPS не используется. Отдельный Telegram-бот владельца — `@GiftPriceControl812_bot`. Секреты API Gift Satellite, Telegram и Redis хранятся только в переменных Vercel. Upstash Redis хранит паузу, последний отчёт и защиту от повторного ежедневного запуска.

Vercel Cron вызывает `/api/daily` по расписанию `0 6 * * *` UTC. Для Hobby точная минута не гарантируется. При активной `/pause` задача ничего не меняет и не присылает утренних сообщений. `/resume` разрешает следующую ежедневную проверку. Codex heartbeat в текущем чате запланирован на 10:15 по Москве для дополнительного анализа свежих данных; он не должен дублировать штатный отчёт Vercel.

11 октября 2026 через документированный Gift Satellite API (`Authorization: Token …`) подтверждены чтение и запись `/user/update-subscription/:id`. План расширен 18 октября после проверки продаж точных моделей Black за 24 часа и 7 дней и предложений пяти площадок. Семь исходных слотов:

Дополнительные 21 точная модель Black и лимиты хранятся в закрытой переменной Vercel `PRIVATE_PORTFOLIO_PLAN`; в публичном репозитории находится только алгоритм `portfolio.js`. Ручная `/apply28 N` обрабатывает пакет N от 0 до 6 по три слота, каждый раз повторно проверяя продажи, текущие предложения, баланс на одну покупку с 3% комиссией и паузу. Одновременная сумма лимитов может превышать баланс по прямому решению владельца. Это не гарантирует, что все сработавшие предложения можно будет оплатить. Дневная задача проверяет 7 исходных и 21 новый слот. Новые точные модели требуют завершённых продаж за 24 часа и 7 дней; лимит не выше `(Q1 недели × 0,92 − 3 TON) / 1,03`, текущего минимума минус 2 TON и опубликованного потолка. Если точных продаж стало мало, активный новый слот выключается. Каждая запись проходит проверку паузы непосредственно перед PUT и подтверждается повторным GET. Отчёт доступен через `/report`. `/positions`, `/models`, `/cross`, `/variant`, `/variantcross`, `/variants`, `/fees` и другие команды дают данные для анализа. Другие фоны не включены: точные сочетания модели и фона пока не прошли проверку по завершённым продажам и расходам.

Отключение старых слотов через API провайдера сбросило их цену автопокупки и количество до пустого значения и нуля. Чтобы вернуть прежнюю стратегию, эти настройки нужно задать заново. Для Lol Pop используется существующий выключенный слот Snoop Dogg; Instant Ramen и Pool Float включаются в уже существующих слотах. Новые слоты не покупаются. API покупки/продажи подарков этим проектом не вызывается. Автопокупку по активным слотам осуществляет сам Gift Satellite. `/pause` останавливает только этот контроллер и его сообщения, но **не** выключает автопокупку Gift Satellite по уже установленным лимитам.

Функция `/api/telegram` принимает только подписанный webhook и команды владельца в личном чате. `/api/daily` принимает только секрет Vercel Cron. Падение Redis запрещает записи. Перед каждым изменением контроллер проверяет актуальную цену рынка; наблюдаемые цены и частота сделок не гарантируют прибыльной перепродажи. Автоматическая продажа подарков и полная копия Mini App не реализованы.

Тесты: из каталога `agent` выполнить `node --test *.test.js`. Они используют поддельный API и не проводят платежей.

До первой успешной команды владельца /apply28 N новые слоты в ежедневном задании не обрабатываются. После неё ежедневная проверка включает весь портфель.
